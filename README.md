# AI Startup Scouting Agent (Google Sheets + Apps Script + Gemini)

A lightweight **AI agent** that scouts accelerators, discovers portfolio startups, and generates conservative one-line value propositions using **Gemini** — all persisted in Google Sheets with **idempotent upserts**, **error isolation**, and **logging**.

## Why this project
The goal is to automate a common business task: **startup & market scouting**.
Instead of a one-off script, this behaves like an **agentic workflow**:
- goal-driven actions (discover → extract → enrich)
- tool usage (web fetch + parsing + LLM)
- memory (Google Sheets as state)
- robustness (skip + log, no full crashes)

## Architecture (Agent view)
**Memory:** Google Sheets  
**Tools:** UrlFetchApp (web), Sheets API (storage), Gemini API (reasoning)  
**Orchestration:** Apps Script menu actions

### Agent pipeline
1. **Scouting accelerators** (seed batch)
2. **Update startups** from accelerator portfolio pages
3. **Generate missing value propositions** (only for rows without `value_proposition`)
4. Log all events into a dedicated `logs` tab

## Google Sheet schema
This project uses **3 tabs**:

### 1) `accelerators`
| column | description |
|---|---|
| website | accelerator hostname (primary key, normalized) |
| name | accelerator name |
| country | accelerator country |
| source_url | where it came from (seed or discovery URL) |
| created_at | ISO timestamp |

### 2) `startups`
| column | description |
|---|---|
| website | startup hostname (primary key, normalized) |
| name | startup name (optional) |
| country | startup country (optional) |
| accelerator | accelerator hostname (foreign-key-like reference) |
| source_url | portfolio page where it was found |
| created_at | ISO timestamp |
| value_proposition | one-line value proposition generated by Gemini |
| value_prop_generated_at | ISO timestamp |
| value_prop_model | Gemini model used |

### 3) `logs`
| column | description |
|---|---|
| ts | timestamp |
| level | INFO/WARN/ERROR |
| action | which step produced the log |
| message | human readable message |
| meta_json | structured context |

## Setup
### 1) Create the Google Sheet
Create a new Google Sheet with 3 tabs:
- `accelerators`
- `startups`
- `logs`

Use the exact headers described above (row 1).

### 2) Add the Apps Script
Open: **Extensions → Apps Script**  
Paste the content of `apps-script/Code.gs`.

### 3) Configure Gemini API key (secure)
In Apps Script:
- **Project Settings → Script Properties**
Add:
- `GEMINI_API_KEY` = your Gemini API key (Google AI Studio)
Optional:
- `GEMINI_MODEL` = `gemini-1.5-flash` (default) or `gemini-1.5-pro`

## How to run
Reload the spreadsheet to see the menu:
**AI Startup Scouting Agent**

Run in order:
1. **Scouting accelerators (seed batch)**
2. **Update startups from accelerators**
3. **Generate missing value_proposition**

## Robustness & idempotency
- Websites are normalized to hostnames (`https://www.example.com/x` → `example.com`)
- Insert operations are **idempotent** (duplicates skipped)
- Each fetch/LLM call is isolated with try/catch → errors do not stop the whole job
- Every issue is logged to the `logs` tab

## Limitations
- Accelerator websites are heterogeneous; portfolio pages may be missing or protected
- Link extraction is heuristic; some non-startup links may appear (blocklist mitigates this)
- Value propositions are generated from limited website text; output is intentionally conservative
